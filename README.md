# 📝 Notes Management System

A simple Notes Management System built using **Spring Boot**, **MySQL**, **HTML**, **CSS**, and **JavaScript**.

## 🚀 Features

- Create a new note
- View all notes
- Update existing notes
- Delete notes
- Responsive user interface
- REST API with Spring Boot
- MySQL database integration

## 🛠️ Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- HTML5
- CSS3
- JavaScript
- Maven

## 📂 Project Structure

```
notes-management
├── src
├── pom.xml
├── mvnw
├── mvnw.cmd
└── README.md
```

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/velpularahul05-boop/notes-management-system.git
```

2. Open the project in IntelliJ IDEA or VS Code.

3. Configure your MySQL database in:

```
src/main/resources/application.properties
```

4. Run the application.

5. Open your browser and visit:

```
http://localhost:8081
```
